## 🚀 كيف ترفع التطبيق على GitHub (3 دقائق)

### الطريقة 1: من Android Studio (الأسهل)
1. في Android Studio: VCS > Enable Version Control Integration > Git
2. VCS > Share project on GitHub > أدخل اسم المستودع vulnfusion-diamond-v8
3. اضغط Share

### الطريقة 2: من سطر الأوامر (المحترفين)
```bash
# 1. فك ضغط المشروع
cd VulnFusion-Diamond-v8

# 2. تهيئة Git
git init
git add .
git commit -m "VulnFusion Diamond v8.0 - 7 robots + self-healing guardian"

# 3. أنشئ مستودع جديد على github.com (لا تضف README)
# اذهب لـ github.com/new > اسم: vulnfusion-diamond-v8 > Create repository

# 4. اربطه وارفعه
git remote add origin https://github.com/YOUR_USERNAME/vulnfusion-diamond-v8.git
git branch -M main
git push -u origin main
```

### الطريقة 3: رفع ملف ZIP مباشرة على GitHub
1. اذهب لـ github.com/new > أنشئ مستودع
2. اضغط uploading an existing file
3. اسحب ملف ZIP وارفعه
